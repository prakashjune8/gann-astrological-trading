## 2. The Square of Nine: Circular Arithmetic Spiral & Price-Time Squaring

$$\Delta \sqrt{P} = \frac{\theta}{180^\circ}$$

### Bidirectional Conversion Formulas

#### A. Price to Square of Nine Longitude ($\text{Price} \to \text{Degree}$):
$$\theta = \left(\sqrt{P} \pmod 2\right) \times 180^\circ$$
- *Example:* Nifty 50 at $P = 24,350$:
  - $\sqrt{24350} \approx 156.044865$
  - $156.044865 \pmod 2 = 0.044865$
  - $\theta = 0.044865 \times 180^\circ = \mathbf{8.076^\circ}$ ($08^\circ\text{Aries }05'$).

#### B. Longitude to Target Price Ladders ($\text{Degree} \to \text{Price}$):

$$k = \left\lfloor \frac{\sqrt{P_{\text{ref}}} - \frac{\theta}{180^\circ}}{2} \right\rfloor$$
$$P_{\text{Support}} = \left(2k + \frac{\theta}{180^\circ}\right)^2, \quad P_{\text{Resistance}} = \left(2(k + 1) + \frac{\theta}{180^\circ}\right)^2$$

## 5. Algorithmic Reference Implementation

```python
import math
from datetime import date, datetime, time, timedelta

def price_to_sq9_degree(price: float) -> float:
    """Convert market price to its exact degree on the Square of Nine (0° to 360°)."""
    if price <= 0:
        return 0.0
    return ((math.sqrt(price) % 2.0) * 180.0) % 360.0

def sq9_price_ladder(degree: float, ref_price: float) -> tuple[float, float]:
    """Calculate Square of Nine harmonic support and resistance bracketing ref_price."""
    offset = (degree % 360.0) / 180.0
    k = math.floor((math.sqrt(ref_price) - offset) / 2.0)
    sup = (2.0 * k + offset) ** 2
    res = (2.0 * (k + 1) + offset) ** 2
    if sup > ref_price:
        sup, res = (2.0 * (k - 1) + offset) ** 2, sup
    return sup, res

def session_angle_to_time(midpoint: datetime, degree: float, total_session_mins: float = 375.0) -> tuple[datetime, datetime]:
    """Calculate Left (-deg / Morning) and Right (+deg / Afternoon) timestamps from session midpoint."""
    scale_min = total_session_mins / 360.0
    offset = timedelta(minutes=degree * scale_min)
    return midpoint - offset, midpoint + offset
```
